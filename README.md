# An efficient two level tabu search algorithm for the quadratic knapsack problem with setup

The software and data in this repository are a snapshot of the software and data used in the research reported in the paper *An efficient two level tabu search algorithm for the quadratic knapsack problem with setup* by Huan-Huan Tan, Qing Zhou, Jin-Kao Hao and Zhang-Hua Fu.

The 420 benchmark instances used in our draft were friendly provided in the Galli et al. [refer to [3]]. To facilitate the further research, we upload the instances here.

The solution certificates are given in 'solutions' directory.

The source code given in 'src' directory implements the proposed CCILS method described in our paper.

## Materials

This repository includes the following materials:

- Benchmark instances used in our paper (see `instance_QKPS/`).
- Source code of the proposed TLTS algorithm (see `source_code/`).
- Best solutions found by TLTS (see `solutions/`).
